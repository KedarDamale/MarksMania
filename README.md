# MarksMania

MarksMania is a full-stack student marks management platform for recording academic information, monitoring performance, and presenting results in a clear dashboard.

## Highlights

- Secure account registration, sign-in, email verification, and password recovery.
- Add and manage student records.
- Organize subjects and enter academic marks.
- View marks and performance in a dedicated dashboard.
- Explore result trends through interactive charts.
- Generate downloadable PDF result documents.

## Built with

- MongoDB, Express, React, and Node.js
- Vite
- Tailwind CSS
- Chart.js
- jsPDF
- Zustand

## Project structure

- `frontend/` — React and Vite interface for the dashboard, student, subject, and marks workflows.
- `backend/` — Express API with MongoDB models, authentication, and student-record endpoints.

## Project status

This repository contains the MarksMania application source. A public deployment URL has not been configured for the project.
